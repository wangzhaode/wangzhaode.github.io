2026.03.06 周五的光

2026-03-06

上午九点半，OpenClaw 准时推送来 MNN 的信息。

看到 MNN 登上了 GitHub Trending C++ 榜单第一。愣了一下。压过 TensorFlow，压过 Godot——端侧推理引擎，在一堆老牌项目里冒了头。

中午和隔壁团队的前端兄弟们去食堂吃万荣烤鸭。周五的中午，人不少，烤鸭还行。

下午的园区，阳光很好。周五下午总是美好的。

下午有两个会议，中间的时间用来处理开源反馈。最近积了二十多个 PR，五十多个 issue。PR 的代码一个个看过，能合并的合并，该关的关。issue 处理得少些。社区活跃是好事，但维护确实费时间——每个问题都要读代码、验证，MNN 跑在端侧，同样的代码 Linux 上没问题，到了 Windows 或手机上就出 bug，复现本身就成本高。给 PR 加了 AI Review，但效率提升不大，AI 能读代码，但现在的 Agent 还搭不起来验证的闭环。

晚上跟高中老友打了两把 LOL。放松一下。

周五。榜单第一，阳光不错，老友开黑，早点休息。
